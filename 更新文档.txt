暗黑破坏神 II 重制版 - 存档编辑器（D2R RotW Editor）v2.0.1 项目历史与改动记录

v2.0.1 更新文档
----------------------------------------------------------------
一、项目来源与核心改造
----------------------------------------------------------------
1. 项目前身是《暗黑破坏神 II 重制版》Reimagined Mod 的修改器
   （Reimagined.html）。本次将其整体改造为「暗黑2重制版官方版本」
   的存档编辑器（Editor_v2.0.1.html）。

2. 数据加载方式改造：
   - 去除「优先加载网络数据」功能，只保留读取本地数据；
   - 编辑器不再发起任何网络请求，断网可用；

3. 编辑器自带数据全部替换为官方数据：
   数据源为《暗黑破坏神 II：重制版》"术士君临"Reign of the Warlock
   中文版 v3.3.93854 客户端。

4. 默认语言设置为简体中文：编辑器启动时默认以简体中文显示，
   并可在右下角语言选择器随时切换（仅当前会话生效）。

----------------------------------------------------------------
二、数据与官方化
----------------------------------------------------------------
5. 新建角色物品修正：新建存档时不再生成官方数据中不存在的
   code=bag 物品，仅保留 charstats.txt 定义的各职业初始物品，
   并支持官方 RotW 版术士（Warlock）职业。

6. Data 目录全面官方化：凡官方客户端数据目录中存在的文件，
   全部替换为官方 v3.3.93854 版本的数据。

7. 官方套装/暗金数据重建：
   - 从官方 hd/items/sets.json、uniques.json 提取数据，
     并按 Data\sets.json、uniques.json 的结构重新生成同名文件；
   - 移除重新生成后的 sets.json、uniques.json 中非官方数据条目。

8. items.json 官方化：参照上述方式，从官方文件提取 items.json
   数据，仅保留官方条目。

9. 数据目录精简：删除 Data 目录下未用到的冗余文件，最终保留
    编辑器实际引用的 23 个官方数据表（.txt）、9 个核心数据（.json）、
    9 个本地化字符串表、27 个任务图标、8 个职业初始存档模板及
    按需加载的物品精灵图。保留未替换：item_stat_ranges.txt、
    界面文案 GildLocalization.json、少量编辑器自用元数据。

10. 共享仓库子面板官方化：「共享仓库」标签页的 Gems（宝石）、
    Runes（符文）、Materials（材料）三个子面板内容改为官方数据：
    宝石面板 = 官方宝石；符文面板 = r01–r33 全部符文；材料面板 =
    官方材料（钥匙、首领器官、赦免之证、世界之石碎片、超级材料、
    回复药水）。

----------------------------------------------------------------
三、界面与布局
----------------------------------------------------------------
11. 标签页顺序调整：
    角色 → 技能 → 任务 → 传送点 → 佣兵 → 物品栏 → 仓库 → 共享仓库。

12. Vault / Grail 标签页：
    - 彻底删除 Grail 和 Vault 标签页及其相关代码，确保其他功能
      不受影响。

13. 删除新建角色界面的 ADVANCED OPTIONS 按钮。

14. 背包 / 仓库网格尺寸调整：
    - 角色背包：10×4 → 13×8（104 格）；
    - 仓库 / 共享仓库：10×10 → 15×10（150 格）；
    - 新建角色时背包内初始物品改为从左上角开始放置。

15. 物品编辑相关界面文案：
    - Edit Item 按钮文字改为「编辑」；
    - 高级选项面板由英文翻译为简体中文。

16. 高级选项默认项：将「显示物品精灵图」与「允许编辑物品
    （Allow Item Editing）」两项设为默认勾选状态。

17. 物品编辑策略：
    - 武器、护甲、戒指/项链/珠宝、护身符、暗金、套装、符文之语
      使用完整属性编辑器；
    - 杂项/消耗品（药水、宝石、符文、卷轴、箭矢、任务物品等）
      字节布局紧凑、无可编辑属性列表，以只读摘要打开（可查看
      名称/代码/品质，仍可移动/删除/复制）。

18. 物品栏 / 仓库 / 共享仓库警告页：
    - 「物品栏」「仓库」标签页加载角色后可直接编辑，不再显示
      警告确认页；
    - 两标签默认样式与其他无警告标签一致（移除暗红危险标记）；
    - 「共享仓库」标签页仍保留警告确认页，点 CONTINUE 后解锁，
      未解锁前标签保留暗红危险标记；警告正文为「共享仓库预览已
      支持，但可能会发生错误。只有在您理解并接受这一点时才继续」。

19. 共享仓库标签页按钮：顶部依次为「浏览 .d2i / 注入编年史 /
    保存编年史」三个按钮，样式统一为 btn-primary 主按钮。

20. 共享仓库 Tooltip：共享仓库物品的鼠标 Tooltip 不显示编辑按钮，
    与物品栏/仓库区分。

21. 编辑器页面按钮：编辑器右上叫依次添加「D2Core / GitHub /
    Download」三个按钮，点击分别跳转至对应网页。

----------------------------------------------------------------
四、物品系统与操作修复
----------------------------------------------------------------
22. 修复物品栏 / 仓库插入装备失败：此前在物品栏或仓库页面插入
    装备时，暗金武器、暗金护甲、套装物品、杂项/消耗品 4 类数据
    无法正确打开及操作；修复后均可正常插入、查看、编辑、移除。

23. 支持中文角色名：修复游戏角色不支持中文名的问题，编辑器可
    设置中文字符名称（游戏侧是否支持由游戏决定）。

----------------------------------------------------------------
五、启动器
----------------------------------------------------------------
24. 启动器：编写 D2REditorLauncher.py，并将编辑器 index.html内嵌显示。

25. 启动器加载方式：
    启动器以本地服务器模式（需用D2REditorLauncher.exe 或本地服务器
    访问，file:// 直开会报CORS 错误）。

26. 保存功能：点击「保存 .d2s」自动将存档保存至启动器所在目录的
    Save 文件夹（不存在则自动创建）；浏览器环境回退为浏览器下载。
    共享仓库「保存编年史」同样自动保存至 Save 文件夹。

27. 右上角链接按钮：
    - 按 Reimagined 样式添加三个带图标的链接按钮：
      D2Core  → https://www.d2core.com/d2r（蓝色）
      GitHub  → https://github.com/songyx090818/D2R-ROTW-EDITOR（橙色）
      Download→ https://pan.baidu.com/s/1Vu2wneJn76PStcfDb9UuUw?pwd=qp5i（绿色）

----------------------------------------------------------------
六、编年史
----------------------------------------------------------------
28. 编年史功能：编年史100%进度数据以 base64 常量内嵌在页面脚本中，
    注入编年史功能集成进编辑器前端。

29. 注入编年史：共享仓库「注入编年史」按钮遍历共享仓库各 tab
    （每 tab 以 64 字节头开始），凡 tabType==2 或其正文以编年史魔数
    C0 ED EA C0 开头即视为编年史 tab，将其重建为 64 字节头 + 编年史
    正文（size 回写至头偏移 +16，tabType 置 2），其余 tab 原样保留；
    注入结果仅作用于内存数据，需再保存才写回文件。
