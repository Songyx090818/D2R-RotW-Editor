# 暗黑破坏神 II 重制版 - 存档编辑器 v2.0.1

基于浏览器的《暗黑破坏神 II：重制版》`.d2s` 存档修改器（**官方离线版**）。读取官方存档并解析为标签页界面；修改先作用于内存数据中，**保存时才写入文件**，默认不覆盖原文件。

## 快速开始

双击 `D2REditorLauncher.exe`（启动器自动启动本地服务并内嵌编辑器，无需装 Python；需系统 WebView2 Runtime，Win 10 / 11 一般自带）→ 打开/拖入 `.d2s` → 修改各标签页 → 点 **Save .d2s** 保存。

> ⚠️ 不要用 `file://` 直接双击 `Editor_v2.0.1.html` 打开——浏览器 CORS 会拦截本地数据，报 "Failed to Load Critical Data"。修改存档前请**务必备份原文件**；物品回写为实验性，出错用备份恢复即可。

## 标签页：功能与使用

- 顶部标签顺序：**角色 → 技能 → 任务 → 传送点 → 佣兵 → 物品栏 → 仓库 → 共享仓库**。
- 已彻底删除 Grail / Vault（圣杯 / 编年史）标签页及相关代码，删除 Data 文件夹内冗余文件。

### 角色（Character）
修改姓名（**支持中文**）、职业、等级、经验、未分配属性点、核心属性（力量/敏捷/活力/精力）、抗性、金币；生命/法力由活力/精力自动计算。改等级会联动经验值与剩余点数，改完点 Save 应用。

### 技能（Skills）
调整技能点剩余（0–250）与各技能等级（技能树中 +/− 或直接输入，含上限约束）。技能树按职业三页展示，与游戏内布局一致。

### 任务（Quests）
三个难度（普通/噩梦/地狱）独立，按幕（I–V）列出全部任务。点击在「未开始/进行中/已完成」间切换；支持当前难度的 **Complete All / Clear All** 快捷按钮。

### 传送点（Waypoints）
三个难度独立，按幕列出。点击切换「激活/关闭」；城镇传送点始终激活；支持 **Activate All / Clear All** 快捷按钮。

### 佣兵（Mercenary）
纸娃娃装备槽（头盔、武器、护甲）。点击空槽插入装备、点击已装备物品查看/移除、可拖放更换；保存时一并应用（applyMerc）。

### 物品栏（Inventory，装备 + 背包）
加载角色后**可直接编辑**（不再显示物品栏警告确认页）；顶部「物品栏」标签使用与其他标签一致的默认样式（不再暗红标记）。
- **纸娃娃装备槽**：主/副手武器、头盔、项链、护甲、手套、靴子、戒指×2、腰带。
- **背包网格：13 × 8（104 格）**；腰带 4 列，只放药水。
- 点击空格子（或装备槽 **+ Add**）插入新物品（可设孔数、ilvl、满变量）；点击物品查看 Tooltip / 编辑 / 移除；网格内拖放移动；顶部搜索框按名称/代码定位。

### 仓库（Stash，个人仓库）
随 `.d2s` 存档一起保存，属于单个角色。网格 **15 × 10（150 格）**；加载角色后**可直接编辑**（不再显示仓库警告确认页），顶部「仓库」标签使用与其他标签一致的默认样式（不再暗红标记）；操作同物品栏（点击查看/编辑/移除、空格插入、拖放、搜索）。

### 共享仓库（Shared Stash）
独立于角色的 `.d2i` 文件，全角色共享。首次进入显示确认警告（文本为「共享仓库预览已支持，但可能会发生错误。只有在您理解并接受这一点时才继续」），点 **CONTINUE** 后解锁；未解锁前顶部「共享仓库」标签保留暗红危险标记（对应警告提示）。顶部依次为 **浏览 .d2i / 注入编年史 / 保存编年史** 三个按钮（样式统一为 btn-primary 主按钮）：

- **浏览 .d2i**：加载共享仓库后显示网格 **15 × 10（150 格）**，可正常插入/查看/移动/删除/复制。
- **注入编年史**：将内嵌的编年史数据（100% 完成度）注入到共享仓库的编年史 tab（作用于内存数据，需再保存才写回文件）。实现上遍历共享仓库各 tab（每 tab 以 64 字节头开始），凡 tabType==2 或其正文以编年史魔数 `C0 ED EA C0` 开头即视为编年史 tab，将其重建为 64 字节头 + 编年史正文（size 回写至头偏移 +16，tabType 置 2），其余 tab 原样保留；编年史数据注入功能已集成进编辑器前端（编年史正文以 base64 内嵌于页面脚本），无需外部脚本。
- **保存编年史**：将当前共享仓库写入启动器 `Save/` 目录（保持 `.d2i` 后缀，浏览器环境回退为下载）。

其中 **Gems / Runes / Materials** 子面板已改用**官方 v3.3.93854** 数据：宝石面板官方宝石、符文面板 r01–r33 全部符文、材料面板官方材料（钥匙、首领器官、赦免之证、世界之石碎片、超级材料、回复药水）。共享仓库物品的 Tooltip **不显示编辑按钮**，与物品栏/仓库保持区分。

> **物品编辑策略**：武器、护甲、戒指/项链/珠宝、护身符、暗金、套装、符文之语 → 完整属性编辑器；杂项/消耗品（药水、宝石、符文、卷轴、箭矢、任务物品等）字节布局紧凑、不携带可编辑属性列表，以**只读摘要**打开（可查看名称/代码/品质，仍可移动/删除/复制）。

## 保存

- 点 **Save .d2s**：存档自动保存到启动器所在目录的 **`Save/`** 文件夹（不存在自动创建）；浏览器环境则回退为浏览器下载。
- 共享仓库页点 **保存编年史**：将当前共享仓库 `.d2i` 自动保存到启动器 `Save/` 文件夹（保持 `.d2i` 后缀，浏览器环境回退为下载）。
- **自动保存**（可选开启，约 2.5 秒防抖写回，需浏览器授权）：内嵌模式下不可用（子帧无法调用文件系统授权），请用 Save 按钮保存。

## 高级选项（右下齿轮）

界面已简体中文化。「显示物品精灵图」与「允许编辑物品」两项**默认勾选**：前者控制用 `Data/sprites/` 精灵图渲染物品格，后者控制物品详情是否显示 **「编辑」** 按钮（关闭则隐藏）。

## 常见问题

- `file://` 打开报 "Failed to Load Critical Data" → 请用 `D2REditorLauncher.exe` 或本地服务器访问。
