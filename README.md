# 暗黑破坏神 II 重置版 — 存档编辑器（D2R RotW Editor）

**版本**：v2.0.5 ｜ **作者**：奈非天的侍从
**性质**：由《暗黑2重置版》Reimagined Mod 修改器改造而来的**官方离线存档编辑器**
**运行**：Windows 桌面程序 `D2REditorLauncher.exe`（HTML 编辑器整体内嵌于启动器，无需外部服务器）

---

## 一、项目简介

本工具是一款《暗黑破坏神 II 重置版》（D2R）官方版的角色存档编辑器，可读取、查看并修改
.d2s 角色存档、.d2i 共享仓库存档，支持创建新角色、编辑物品、整理仓库等功能。

- **官方数据**：全部数据来源于官方客户端（CN v3.3.93854）。
- **完全离线**：不依赖任何网络数据源，所有数据本地读取。
- **默认中文**：启动默认简体中文，支持简体/繁体及多语言切换。

---

## 二、主要功能

1. **新建角色**：支持 8 个职业（亚马逊/法师/死灵/圣骑/蛮子/德鲁伊/刺客/术士），
   初始物品严格按 charstats.txt 定义，背包从左上角放置，支持中文角色名。
2. **角色编辑**：查看/修改角色基础属性、技能、任务、传送点、佣兵等。
3. **物品编辑**：物品栏、仓库、共享仓库、佣兵、身体各栏位可插入/移除/编辑物品，
   支持暗金、套装、符文之语、宝石、符文、杂项/消耗品等分类。
4. **共享仓库**：宝石页、符文页、材料页已按官方数据布局；
   支持浏览/注入/保存编年史（.d2i）。
5. **配装保存**：物品栏配装 Build 1-5 存档。
6. **存档保存**：点击“保存.d2s”自动存入启动器所在目录的 Save 目录（不存在则自动创建）。
7. **撤销**：支持撤销操作，避免误改。

## 四、使用方法

1. 双击运行 `D2REditorLauncher.exe`，编辑器随启动器打开。
2. **打开存档**：点击“打开 .d2s”（或拖放文件），选择角色存档；共享仓库可加载 .d2i。
3. **新建角色**：点击“创建新角色”→ 输入名称、选择职业 → 生成，再“保存.d2s”。
4. **编辑物品**：进入物品栏/仓库/共享仓库，点击物品可查看详情，
   点“编辑”修改属性，或用插入面板添加物品。
5. **保存**：点击“保存.d2s”，自动存入 `Save` 目录（不存在则自动创建）；
   共享仓库保存为 .d2i。
6. **高级选项**：可开关物品精灵图显示、允许编辑物品等（默认勾选）。

> 提示：建议始终保存到新位置，编辑器不会覆盖您打开的原始文件。
