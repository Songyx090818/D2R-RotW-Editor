# D2R RotW Editor — 暗黑破坏神 II 重置版官方离线存档编辑器

> 前身为《暗黑破坏神 II 重置版》Reimagined Mod 修改器，已全面改造为**官方版本离线存档编辑器**，去除网络数据加载，数据全部来自官方客户端（v3.3.93854），只保留本地数据，默认简体中文。

---

## 功能特性

- **8 大标签页**：角色、技能、任务、传送点、佣兵、物品栏、仓库、共享仓库
- **官方数据**：编辑器全部数据来自官方客户端（包含 data 目录、sets.json、uniques.json、items.json 等官方数据提取），不含 Mod 专属内容
- **离线运行**：编辑器代码与数据内嵌进启动器，无需本地服务器、无需网络，所有功能无损
- **界面网格**：角色背包 13×8，仓库与共享仓库 15×10；新建角色背包物品从左上角放置
- **新建角色**：仅保留 charstats.txt 所定义的各职业初始物品
- **编年史**：共享仓库支持"注入编年史""保存编年史"（.d2i 后缀），自动保存至项目 Save 目录（不存在则自动创建）
- **自动保存**：点击"保存 .d2s"自动存至启动器所在目录的 Save 目录（不存在则自动创建）
- **中文支持**：简体/繁体语言，界面已全面汉化；支持中文角色名
- **右上角链接**：D2CORE、GITHUB、DOWNLOAD 快捷入口

---

## 使用方法

1. 将 `D2REditorLauncher.exe` 与 `Data` 文件夹放在同一目录。
2. 双击运行 `D2REditorLauncher.exe`，编辑器自动打开。
3. 加载角色存档（.d2s）或共享仓库存档（.d2i）开始编辑（共享仓库仅支持编年史操作）。
4. 通过各标签页修改角色属性、技能、任务、传送点、佣兵与物品。
5. 点击"保存 .d2s / 保存编年史.d2i"，自动保存至 Save 目录。
